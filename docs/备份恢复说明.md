# 备份恢复说明

## 1. 需要备份什么

至少备份三类内容：

- MySQL 数据库
- `.env`
- `configs/sources.yaml`

如果要做到更稳，也建议一起备份：

- `deploy/systemd/*.service`
- `deploy/systemd/*.timer`
- `docs/`

## 2. MySQL 逻辑备份

示例：

```bash
mysqldump -h 127.0.0.1 -u scraper -p --single-transaction --default-character-set=utf8mb4 scraper > /backup/scraper_$(date +%F).sql
```

建议：

- 每天凌晨备份一次
- 保留最近 7~30 天
- 备份文件单独存到非系统盘或对象存储

## 3. 配置文件备份

```bash
cp /opt/zj-agent/.env /backup/zj-agent.env.$(date +%F)
cp /opt/zj-agent/configs/sources.yaml /backup/sources.yaml.$(date +%F)
```

## 4. 恢复步骤

### 恢复数据库

```bash
mysql -h 127.0.0.1 -u scraper -p scraper < /backup/scraper_2026-04-25.sql
```

### 恢复配置

```bash
cp /backup/zj-agent.env.2026-04-25 /opt/zj-agent/.env
cp /backup/sources.yaml.2026-04-25 /opt/zj-agent/configs/sources.yaml
```

### 恢复服务

```bash
sudo systemctl restart zj-agent-web.service
sudo systemctl restart zj-agent-weekly.timer
```

## 5. 恢复后验证

恢复后至少检查：

- 后台能否登录
- 最近 job run 是否可见
- `clue_pool` 是否可查
- 飞书测试通知是否正常
- 周任务能否手工跑通
