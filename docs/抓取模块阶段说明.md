## 已实现能力

### 抓取阶段

- 来源配置驱动，新增来源优先通过 `configs/sources.yaml`
- 列表页发现、分页识别、详情页抓取
- PDF / DOCX 附件解析
- URL 去重、内容 hash 去重、近似标题去重
- 登录页 / 后台页 / 脏 URL 拦截
- 明显噪声标题过滤
- 周更模式默认只扫首页

### 提取阶段

- 新增 `extracted_clues` 表，专门保存 AI 结构化提取结果
- AI 一次输出这些核心字段：
  - `keep`
  - `clue_type`
  - `investment_relevance`
  - `relevance_score`
  - `core_technology`
  - `application_scenarios`
  - `transformation_signals`
  - `summary`
  - `reason_tags`
  - `decision_reason`
- 提取阶段可直接过滤掉不是目标科技成果线索的新闻
- 明显噪声页会在提取阶段直接丢弃，不调用 AI

### 入池阶段

- 新增 `clue_pool` 表，作为正式业务线索池
- 入池条件默认：
  - `extracted_clues.status = kept`
  - `investment_relevance in ('high', 'medium')`
  - `relevance_score >= 70`
- `clue_pool` 只保留业务消费所需的最小字段，并通过 `extracted_clue_id` 回链到完整 AI 结果
